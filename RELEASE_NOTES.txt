STEEP RELEASE NOTES

Steep is a modern RAW photo editor forked from RawTherapee.
https://github.com/cheetohsum/Steep

Steep is based on RawTherapee by the RawTherapee contributors.



IN GENERAL

Start by reading the documentation:
https://github.com/cheetohsum/Steep

Steep supports most raw formats, including Pentax and Sony Pixel Shift, Canon Dual-Pixel, and those from Foveon and X-Trans sensors.
If you're wondering whether it supports your camera's raw format, first download Steep and try for yourself. If a raw format is not supported it will either not open, or the preview in the Editor tab will appear black, white, or have a strong color cast - usually magenta.

In order to use Steep efficiently you should know that:
- You can scroll all panels using the mouse scroll-wheel.
- You can right-click on a tool's name to automatically expand it while collapsing all others.
- To change slider values or drop-down list items with the mouse scroll-wheel, hold the Shift key. This is so that you can safely scroll the panels without accidentally changing a slider or other tool setting.
- All curves support the Shift and Ctrl keys while dragging a point. Shift+drag makes the point snap to a meaningful axis (top, bottom, diagonal, other), while Ctrl+drag makes your mouse movement super-fine for precise point positioning.
- There are many keyboard shortcuts which make working with Steep much faster and give you greater control.
- All sliders support a fine-tuning mode which you can toggle by pressing the Shift key while dragging a slider.



NEWS RELEVANT TO PACKAGE MAINTAINERS

In general:
- To get the source code, clone from git: https://github.com/cheetohsum/Steep
- Requires GTK+ version >= 3.24.3.
- GTK+ versions 3.24.3 - 3.24.6 have an issue where combobox menu scroll-arrows are missing when the combobox list does not fit vertically on the screen.
- JPEG XL read support depends on libjxl. By default, Steep builds with JPEG XL support if and only if libjxl is present. Use -DWITH_JXL="ON" or -DWITH_JXL="OFF" to explicitly enable or disable JPEG XL support.
- Steep builds with a custom version of LibRaw by default. To use the system LibRaw, use -DWITH_SYSTEM_LIBRAW="ON". Requires LibRaw >= 0.21.
- Steep requires GCC-4.9 or higher, or Clang.
- Do not use -ffast-math, it will not make Steep faster but will introduce artifacts.
- Use -O3, it will make Steep faster with no known side-effects.
- For stable releases use -DCACHE_NAME_SUFFIX=""
- For development builds use -DCACHE_NAME_SUFFIX="5-dev"

To avoid Rust dependencies:
- Build using LunaSVG rendering backend
    - Use -DSVG_BACKEND="lunasvg" and -DWITH_SYSTEM_LUNASVG="ON|OFF"
